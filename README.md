# FASHIONS – Wear Your Confidence

A responsive multi-page fashion e-commerce website built using HTML, CSS, and JavaScript. The project showcases a modern fashion brand with a clean user interface, interactive product collections, and responsive design.

## Project Overview

FASHIONS is a front-end fashion website designed to provide users with an engaging shopping experience. The website features multiple pages, category-based product collections, customer testimonials, newsletter subscriptions, and a contact form.

## How to Run

### Option 1: Open Directly

Open the `index.html` file in your browser.

### Option 2: VS Code Live Server

1. Install the Live Server extension.
2. Open the project folder in VS Code.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

## Key Functionalities

### Product Filtering

Users can filter products by category:

* Women
* Men
* Kids
* Accessories

### Theme Toggle

Switch between Light Mode and Dark Mode. The selected theme is saved using Local Storage.

### Contact Form

Includes:

* Required field validation
* Email validation
* Success/Error messages

### Newsletter Subscription

Users can subscribe using their email address and receive confirmation feedback.
